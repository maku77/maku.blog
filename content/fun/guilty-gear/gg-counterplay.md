Guilty Gear Strive のキャラ別対策メモ。
少しずつ対策していきます。


<img src="/assets/img/ggst/face-axl.jpg" width="40px" height="40px"> アクセル＝ロー (AXL LOW)
----

- 地上から近づくときは、**ダッシュ＆しゃがみガード**。
- 空中から攻めるときは、**ハイジャンプ** or **2段ジャンプ** で頭上まで近づく。アクセルは真上に弱い。
- {{< gg "2P" >}} は中距離まで届く下段攻撃なので、中距離ではしゃがみガード必須。
- {{< gg "236S(鎌閃撃)" >}} は射程は長いが、アクセルは鎌が戻るまで動けない。ガードしたらダッシュで近づく。立ちガード可能。
  - 派生技の {{< gg "[8](曲鎖撃)" >}}（上方向の跳ね上げ）は、しゃがんでいれば当たらないがガード直後にダッシュすると当たってしまう。
    ただし、画面端ぎわくらいの遠距離や、至近距離であれば立っていても当たらない。
  - 派生技の {{< gg "[2](旋鎖撃)" >}}（ヘリコプター）は、見た目に反して下段攻撃。ジャンプ攻撃でカウンターヒットできる。
- 地面がモコモコ迫ってくる {{< gg "41236HS(冬蟷螂)" >}} は投げ技なのでガード不可。すぐにジャンプで避ける。
- 覚醒の {{< gg "236236HS(百重鎌焼)" >}} は最初の体の周りの炎(x2)をガードしたら、前ジャンプ入れっぱなしでコンボへ。
  遠距離で出されたら、飛び道具だけジャンプでかわしてコンボへ。
  中距離で出されたら、最初から前ジャンプを入れていると自分から1段目に当たりに行ってしまうので、一瞬しゃがみガードして体の周りの炎が見えた瞬間に前ジャンプすること（開幕位置がちょうどこの距離）

<img src="/assets/img/ggst/face-aba.jpg" width="40px" height="40px"> アバ (A.B.A)
----

- 特徴
  - 憤嫉モードに入るとすごく強くなるが、**ゲージ切れの憤嫉モード解除時は 10F ガードしかできなくなる**。タイミングを合わせて打撃 or 投げを重ねる。
  - 紛失モードはパラケルス（鍵）を使った攻撃をガードさせると増えていく。
  - <b>結合と変性 (Bonding and Dissolving)</b> {{< gg "214HS" >}}
    - ヒットすると憤嫉モードに入る。
    - ガード時は A.B.A が **-2F**（憤嫉時: 同じ）。
  - <b>変化と感化 (Changing and Swaying)</b> {{< gg "63214P" >}}
    - 嫉妬ゲージが「黄色」まで溜まると自由に憤嫉モードに入れる。
  - <b>牽引と随順 (Haul and Heed)</b> {{< gg "214K" >}}
    - 低姿勢で素早く近づく技。**上半身に当たり判定がない**。
  - <b>戮力と傾動 (Intertwine and Tilt)</b> {{< gg "236K" >}}
    - 斜め上からのドロップキック。**憤嫉モード時は中段** になる。
    - ガード時は A.B.A が **-4F**（憤嫉時: 同じ）。
  - <b>威喝と嗚咽 (Intimidate and Wail)</b> {{< gg "236S" >}}
    - 前進しながらチョップ。
    - {{< gg "6S(抑圧と束縛:Restriction-and-Constraint)" >}} に繋げられる（抑圧と束縛はガード時 A.B.A **-27F** で確反）。嫉妬ゲージがたくさん溜まる。
    - ガード時は A.B.A が **-5F**（憤嫉時: **-2F**）。
  - <b>逆上と驚愕 (Frenzy and Astonishment)</b> {{< gg "214S" >}}
    - 相手の攻撃を受け止めて、嫉妬ゲージを上げる。
  - <b>断罪と情動 (Judgment and Sentiment)</b> {{< gg "(憤嫉時)623HS" >}}
    - 2回攻撃（すくい上げ→叩きつけ）。相手の攻撃を耐える。
    - ガードされても A.B.A が **+4F**。
  - （覚醒）<b>鍵の支配 (The Law is Key, Key is King)</b> {{< gg "632146HS" >}}
    - 無敵あり。通常モードだと憤嫉モードに入る。憤嫉モードだと大ダメージを与えて通常モードに戻る。
    - 2段攻撃だが、**1段目ガードでカウンター確定**。
  - （覚醒）<b>鍵の守護者 (Keeper of the Key)</b> {{< gg "632146K" >}}
    - 相手の地面から攻撃。ガードされても A.B.A が **+6F**。
    - 見てからガードしても間に合うけど、**ガード必須（バックジャンプがおすすめ）**。
      行動中でも紫ロマキャンでガードが間に合う（**ドアが開いた瞬間にロマキャン** or 連打）。
      無敵技や青ロマキャン反撃しようとすると喰らう。
- 憤嫉モードになったらハイジャンプで逃げる。


<img src="/assets/img/ggst/face-anj.jpg" width="40px" height="40px"> 闇慈 (ANJI)
----

- {{< gg "235K(水月の運び)" >}} はくるくる回っているときに投げられる。
- {{< gg "236HS(風神) ~ S(凪刃)" >}} 「緑→青」の順に光るやつは青は下段。ガード時は闇慈 -7F。近ければ {{< gg "2K" >}} や {{< gg "K" >}} で確反 (Punish)。
- {{< gg "236HS(風神) ~ HS(臨)" >}} 「緑→黄」の順に光るやつは黄は中段。ガード時は闇慈 -7F。近ければ {{< gg "2K" >}} や {{< gg "K" >}} で確反 (Punish)。
- トレモで、風神からの中下段二択をガードして反撃、という流れに慣れる。
  - スロット1: {{< gg "f.S HS > 236HS(風神) ~ S(凪刃) ..." >}}。
  - スロット2: {{< gg "f.S HS > 236HS(風神) ~ HS(臨) ..." >}}。


<img src="/assets/img/ggst/face-ven.jpg" width="40px" height="40px"> ヴェノム (VENOM)
----

- 特徴
  - {{< gg "214P/K/S/HS(ボール生成)" >}} {{< gg "K" >}} 配置のボールは生成直後に飛ばせる。
  - {{< gg "41236K(複数ボール生成)" >}} {{< gg "6HS" >}} で全部飛ばせる。
- 硬直の長い基本技が多いので、空中から攻めたい。
- 近距離では、足払いキャンセルから足元に球を出す {{< gg "[2]8HS(カーカスライド)" >}} で固めてくるのが典型的。
  ガードしてもヴェノム有利というトンデモ技だけど、FD で離さないことには始まらない。


<img src="/assets/img/ggst/face-elp.jpg" width="40px" height="40px"> エルフェルト＝ヴァレンタイン (ELPHELT VALENTINE)
----

- 特徴
  - やります！のガトリングだけで（反則的な）中下択ができてしまうので、これだけでもある程度勝ち進められる。何コレ。
  - 遠くで攻撃が当たったときもスライディングで強引にコンボにいける。
- 「やります！」対策
  - レコーディング: {{< gg "f.S 2HS 214S(やります！) ~ P(上から！)x3" >}}
    - {{< gg "2HS" >}} で膝から滑り込んでくるのが見えたら、やります！を {{< gg "6P" >}} で撃ち落とす練習。
    - 2 段目のやります！をガードしてから、3 段目のやります！を {{< gg "6P" >}} で撃ち落とす選択肢もあり。
    - {{< gg "2HS" >}} の膝滑り込みは立ちガードできる。
- 連携にボンボン・ショコラを入れられたらジャンプ
  - ジャンプ攻撃がカウンターヒットになるので、ボンボン・ショコラを見切れれば実はチャンス。
    - 例: ジオヴァーナ: {{< gg "j.HS j.D air-dash j.D > 236236HS(テンペスターヂ)" >}}
  - 地面ぎわの爆弾は立ちガードできるので惑わされない。
- 飛び道具を打つのが見えたら、{{< gg "6P" >}} ですり抜けられる。
- 空中からの飛び道具をダッシュでくぐったら、**空中投げ** にいくのが安全。


<img src="/assets/img/ggst/face-kyk.jpg" width="40px" height="40px"> カイ・キスク (KY KISKE)
----

- {{< gg "236S(スタンエッジ)" >}}
  - 前ジャンプ + バックステップで避けるのが理想だが、慣れが必要。
    - ガードするとカイのテンションゲージが溜まってしまうのでジャンプで避ける。FD してもテンションゲージは溜められてしまう。
    - スタン・エッジの速度は（チャージアタック版も）空中バックダッシュよりも速いので、真上くらいでバックダッシュすれば当たることはない。
  - 前ジャンプから攻撃に行く場合は、先読み気味にジャンプできていないと落とされる。
- {{< gg "236HS(スタンエッジ・チャージアタック)" >}}
  - これで固めてる最中に投げてきたりする ~~反則技~~。
  - ダウンを取っていないのに **近距離で打ってきたら前ジャンプでお仕置き** するとよい。
    すぐに {{< gg "214P(ライトニングストライク)" >}}（雷落とし）してきたらしょうがない（どう対応すればいいのコレ）。
  - 中距離で打ってきたら、**{{< gg "dash 6P" >}} ですり抜けながら反撃** が可能（見極め難しい）。
- {{< gg "236K(スタン・ディッパー)" >}}
  - 超速いスライディングで、見てからガードするのは無理な反則技。**中距離では常に下段ガード** が強いられる。
    ガードすれば確反だが、ほぼロマキャンとセットで出してくるので反撃は無理。
  - 見た目に反して **2 段目は立ちガードできるのでできれば立つ** こと（硬直時間短縮のため）。
- ダイアエクラ
  - ガード側有利だけど距離が離れるのでほぼ反撃不能。**直ガ** できれば確反を取れる。
- フードゥル・アルク
  - 出された瞬間に {{< gg "5P" >}}、{{< gg "5K" >}} あたりで割り込める。キャラによって違うのでトレモで確認しておく。
    - 例: ジオヴァーナ: {{< gg "5K dc.K 214K(セパル)" >}}
  - ガードする場合は必ず **立ちガード** すること。しゃがみガードすると硬直時間が長くなってしまう。
    立ちガード後は発生が早くてある程度リーチのある {{< gg "5K" >}} などで反撃。
    密着で立ちガードできたら投げが確定。
  - 対空必殺技（例: メイのイルカさん・縦 {{< gg "[2]8S" >}} など）なら簡単に返せるキャラもいるが、ジオのソウ・ナセンテ {{< gg "623S" >}} などは最速で出さないと負けor相打ちになる。返した場合は空中コンボへ。


<img src="/assets/img/ggst/face-zat.jpg" width="40px" height="40px"> ザトー＝ONE（ZATO=ONE)

- エディは攻撃して消すことができる。
- {{< gg "236HS(張り合う)" >}} は攻撃しない。ダッシュ投げ or 覚醒必殺技で攻撃するのは OK。


<img src="/assets/img/ggst/face-gio.jpg" width="40px" height="40px"> ジオヴァーナ (GIOVANNA)
----

- 特徴
  - このゲーム内で唯一まともに格ゲーし続けているキャラ。
    理不尽な連携が皆無なので、実力がまともに反映される。
- {{< gg "236K(トロヴァォン)" >}} ドリルになって飛んでくる。反応できれば {{< gg "6P" >}} で簡単に撃墜できる。
- {{< gg "214K(セパルトゥア)" >}} 回し蹴り。ガードしたらジオ不利なので、{{< gg "2K" >}} などで反撃。ジオが常にガードしてくるなら投げにいくのもあり。
- {{< gg "236236HS(テンペスターヂ)" >}} 空中からの急降下蹴り。2.0 からはガード時にジオが不利になった。
- {{< gg "623S(ナセンテ)" >}} は上方向に強いが無敵ではないので気にせずに起き攻めしてよい。覚醒技の {{< gg "632146HS(ヴェンターニア)" >}} は無敵だが、ガードされると終わりなのでそうそう出せるものではない。
- ジオは遠くから攻める方法がステップくらいしかないので、様子見が効果的。
- {{< gg "f.S" >}} の後は下段がないので立ちガード安定。投げは注意。


<img src="/assets/img/ggst/face-jko.jpg" width="40px" height="40px"> ジャック・オー (JACK-O')
----

- {{< gg "2K 2D > 236K(サーヴァントシュート)" >}} のように連携がサッカーボールキックで終わっている場合は、サーヴァントがいなければジャック・オー **-12F** なので、**リーチの長い技で PUNISH** 取れる（例: ジオなら発生 10F の {{< gg "5HS" >}}）。
  サーヴァントがいてもジャック・オー **-7F** なので、いずれにしても攻撃を出しておくのがよい。


<img src="/assets/img/ggst/face-jam.jpg" width="40px" height="40px"> ジャム (蔵土縁 紗夢) (JAM KURADOBERI)
----

- 特徴
  - GGST 2.0 からの参戦キャラ。見切りにくい強化版攻撃、判定の強い百歩沁鐘、攻撃範囲が広すぎる無敵覚醒など優遇されている。
- {{< gg "236HS(龍鎚/りゅうつい)" >}} ... ジャンプから急降下＆スライディング。
  - 青色の強化版だとジャム側ターン継続なので手が出せない。
  - 赤色のノーマル版は下段ガードして {{< gg "2K" >}} などで反撃。
- {{< gg "236K(龍刃/りゅうじん)" >}}
  - 青色の強化版で壁割りすると凄まじいダメージになる（~~たぶんバグ~~）。
  - ガードすれば確定反撃だが、ロマキャンでカバーできるので遠くからぶっ放されることも多い。
- {{< gg "236S(逆鱗/げきりん)" >}}
  - 飛び上がりかかと落とし。見えるなら **ジャンプ攻撃** で反撃。
- {{< gg "214S(爆蹴/ばくしゅう) ~ HS(百歩沁鐘/ひゃっぽしんしょう)" >}}
  - 判定が強すぎるので、出る前に攻撃を置いてくしかない。
  - 攻撃後のバクステを狙うのもあり。
- {{< gg "236P(祓斧/ほちふ)" >}}
  - 当て身投げだけど 5F かかるので、起き上がりに {{< gg "c.S" >}} を重ねにいってよい。
    ただし、無敵覚醒があるので相手ゲージに注意。詐欺飛びなら安全。
- {{< gg "63214HS(兆脚黄龍門)" >}}
  - 無敵時間ありの覚醒必殺技。めちゃくちゃ攻撃範囲が広く、相手の連携中にも割り込めたりする。
  - 通常版の龍鎚のガード後に出したりする。
- 下記のパターンをランダム再生させて反撃練習をする。
  - スロット1: {{< gg "c.S f.S 236S(逆鱗)" >}} → {{< gg "2K" >}} からのコンボ
  - スロット2: {{< gg "c.S f.S 236HS(龍鎚)" >}} → 空投げで反撃（ムズイ）


<img src="/assets/img/ggst/face-jhn.jpg" width="40px" height="40px"> ジョニー (JOHNNY)
----

- ミストファイナーによる横方向の攻撃が主体なので、ジャンプ攻撃で攻めたい。
- ミストファイナー {{< gg "214P(上)" >}} {{< gg "214K(中)" >}} {{< gg "214S(下)" >}}
  - ジョニーが後ろを向くのが見えたら、ミストの発射準備なので、低ダで攻めてみる。
  - ミストはガードすればジョニー不利 (**-15F**)。
  - ミスト構え中は前後に歩けるし、ステップ打ちもできることに注意。Kミストのステップ内はどの距離からでもほぼ届く。
  - **（ジオ）ミストをガード or ぎりぎり躱したら、{{< gg "dash 5HS" >}} で詰め寄る。**
    ミスト連打してた場合はカウンターできる。
- ダッシュ蹴り上げ ({{< gg "2K" >}}) は、ガードしてもジョニーは -5F くらいしか不利にならない。
- テリーボガードのクラックシュートみたいに飛んでくる、{{< gg "236HS(跳躍) ~ HS(空中ディール)" >}} は、ガード位置によってジョニーが -1〜-4F。
  攻撃を出さずにそのまま投げに来ることもある。
- 炎を出す飛び蹴り {{< gg "214HS(燕穿牙/えんせんが)" >}} は中段技。
  ガードすればジョニーやや不利 (**-4F**)。
  空振りなら **-40F** なので必ずとがめること。


<img src="/assets/img/ggst/face-sin.jpg" width="40px" height="40px"> シン＝キスク (SIN KISKE)
----

ガトリングからの中段・下段の二択に慣れる。

- フーフスタンプ {{< gg "214S" >}}（中段）への反撃練習
  - レコーディング: {{< gg "S 2S 214S(フーフスタンプ) 派生S S" >}}
  - {{< gg "214S(フーフスタンプ)" >}} の硬直差は -11F なのでガード後に確反を取れる。
  - {{< gg "派生S" >}} までいくと硬直差は -5F くらいで間合いも離れるので確反は取れない。
    - 間合いが離れた後に必ず {{< gg "S" >}} を出してくるようであれば、長い間合いの攻撃を置いておけばカウンターやパニッシュを取れる（例: ジオヴァーナの {{< gg "5HS" >}} or {{< gg "2D" >}}）。
  - **ジオヴァーナなら、フーフスタンプをガードしたら {{< gg "5HS" >}} 連打しておく** のが安定かも。
    {{< gg "f.S" >}} で反撃しようとすると逆にカウンターをとられるので注意。
- 突進は置き技で咎められるとよい（例: ジオの {{< gg "2D" >}}）。


<img src="/assets/img/ggst/face-sly.jpg" width="40px" height="40px"> スレイヤー (SLAYER)
----

- 特徴
  - {{< gg "2HS" >}} の下段攻撃が強力。倒れているのにずっと拾われ続けてコンボがなかなか終わらない（~~おそらく設計ミス~~）。
- 突進系の技をガンガン出してくるなら、垂直ジャンプやバックジャンプで避けつつ攻撃。
- マッパハンチ
  - ガード後距離が近ければ {{< gg "投げ" >}}。


<img src="/assets/img/ggst/face-sol.jpg" width="40px" height="40px"> ソル・バッドガイ (SOL BADGUY)
----

- 特徴
  - 主人公？というだけで優遇されていそうなキャラ。
  - 判定がやけに強力な {{< gg "f.S" >}} を中心に攻めているだけで勝てたりする。通称腹パン野郎。
- {{< gg "214K(バンディット・ブリンガー)" >}}（地上 or 空中）飛び上がって急降下する攻撃。
  - 頭辺りの高い位置でガードできたら、ソル **-4F** なので **投げ** が PUNISH 確定する。
  - 胸あたりのやや高めの位置でガードしたら、ソル **-4F** だが投げは届かないので {{< gg "c.S" >}} を連打しておくのもあり（8F 以下ならソルの {{< gg "5K" >}} (5F) に勝てる）。
  - 腰〜膝下の低い位置でガードすると、だんだんソルの不利が消えていく **-3F → -0F** が、ガード側有利なので {{< gg "2P" >}} などは入れておく。
    ただし、-0F になった場合は、ソルの {{< gg "2P" >}} や {{< gg "5K" >}} と相打ちになる。
