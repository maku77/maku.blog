    巻き戻し前の準備

    エルミナージュのヒズベルトお姉さんに周回巻き戻しの相談をする前に、知恵のアンクだけは集めておくと、0GP アイテムの売買をすぐに解禁できて盗みがはかどります。

    • 知恵のアンク x10 … No.35 かしこくなりたいニャン → 3フェイム、0GP アイテム売買解禁
      • 店に売ってストックしておく（2 周目で盗みをせずにすぐ 3 周目に入るのであれば必要ない）

    「記録のワンド」を強化するためにフェイムを稼ぎたいときは、下記を宿屋に預けておきます（あるいは装備しておく）。 逆に記録のワンドを強化するつもりがないのなら、フェイムはあまり必要ないかも。

    • イノセント(ソード/シールド/マント) … No.27 純粋なる力 → 3フェイム
    • 氷炎の鎖帷子 … No.28 氷と炎の鎖帷子 → 3フェイム
    • 女神の盾 … No.29 真実の盾の真実 → 3フェイム
    • 黒夢の外套 … No.30 堕落の果てにあるもの → 3フェイム
    • No.31 王の剣、秘められた力
    • No.32 盟友の誓い
    • 印籠 … No.33 ひかえおろう → 3フェイム
    • 賢者の石 … No.34 賢者の石 → 3フェイム

    イベントクリア手順

    周回をまわすだけなら

    1. No.1 冒険者登録試験
      1. トランジェルダ城で謁見
      2. クレイディア洞窟へ入る
      3. コンパスにフェイムを 4 つセット
      4. X:18 Y:5 のスイッチを押す
      5. X:9 Y:10 の隠し扉を通って、X:13 Y:4 の部屋にある指輪を取得
      6. ティオメンテで入り口の上までワープしてフェンデルをスルー（これで以降エンカウントしなくなる）
      7. ディンス王に渡す
    2. No.43 神々の系譜
      1. カレテゴのロジェラ大聖堂で「神について」の話を聞いて フェイムを 3 つゲット。
    3. No.10 ミアマックの心配事
      1. ミアマックの宿屋で話してイベント開始
      2. ヘーメ共同地区のニャンニャンどぐぁで「頭痛薬」を買って渡す → 倉庫利用料がタダになる + フェイムを 4 つゲット。
    4. No.20 エルフ王の異変 / No.3 変幻の指輪
      1. ディンス王に謁見してイベント開始
      2. ノヴァ・カリスのセントラルパレスでカーバンクルジュエルの依頼を受ける
        • カーバンクルジュエルを持っていなければ、光の庭ですぐ取得可能。
          1. 光の庭 1F X:12 Y10 から 2F へ。
          2. 光の庭 2F X:11 Y:7 でカーバンクルを倒してカーバンクルジュエルを取得。
      3. もう一度セントラルパレスに入るとファルネウスがターナに弄ばれている → 変幻の指輪をゲット。
      4. ディンス王に謁見 → イベントクリア。
    5. ヘーメ共同地区のよろず相談所の相談リストを開いて、アイテムを見せるだけでもらえるフェイムをもらっておく
      1. No.25 フェニックスの羽毛 … フェニックスの羽毛を引き渡し → フェイムを 3 つゲット（装備していても引き渡してしまうので注意）
      2. No.27 純粋なる力 … イノセント(ソード/シールド/マント)をパーティが装備していればクリア → フェイムを 3 つゲット
      3. No.28 氷と炎の鎖帷子 … 氷炎の鎖帷子を見せればクリア → フェイムを 3 つゲット
      4. No.30 堕落の果てにあるもの … 黒夢の外套を見せればクリア → フェイムを 3 つゲット
    6. オランド商店にいくとナーウィが悲しんでいるので何度か話す → フェイムを 4 つゲット
    7. No.49 コッペロの鉱石探し
      1. 最後に祭壇に祈りを捧げるためにコッペロの店をオープンしておく必要がある。
      2. ハダーリマス渓谷に入ったら、上端から上のマップにいき、そこから右のマップ（北東エリア）に行く。
      3. 北東エリアの (9, 4) でコッペロを仲間にいれる。
      4. 南西エリアにティオメンテで戻り、右にずっと進んで南東エリアの (16, 4) で鉱石を見つける。
      5. ギガ・バザールに戻ると、オーガに襲われるけど「いいえ」選んでスルー → フェイムを 3 つゲット。
    8. コンパスにフェイムをセット（5 個付けると同一フロア内で反応、6 個でダンジョン内で反応）（5x4 = 20 個あればよい）
      • イルドラハ「創命の指輪」 … 5 or 6 個つける
      • アシュテル「変幻の指輪」 … つけない！（すでに取得済み）
      • ロジェラ「暗滅の指輪」… 5 or 6 個つける
      • ボイド「空間の指輪」… 5 or 6 個つける
      • ナルゥ「時の指輪」… 5 or 6 個つける
      • デーハインの「存在の指輪」… すでに 7 個ついてる （フェイムを稼ぎたい場合は、6 個付けてセーブせずに 4 つの指輪の位置を探す→リセットしてその位置まで行って指輪を取得。ただし、すべてのフェイムを記録のワンドにつぎ込んで、フェイムが 0 個のまま闇の巫女（竜の牙 9F）まで進んでしまうと、ボスが超強力なアイロークになって詰んでしまうので、1つは適当に付けておくと安全。記録のワンドにつけるのを後回しにするのでも大丈夫）
    9. ランダム配置された 4 つの指輪を探す No.2〜6 創命／変幻／暗滅／空間／時の指輪
      • ジェスベイラーなど、まだ登場していないダンジョンに指輪が配置されていそうだったら、イルドラハ寺院で流転の儀式 (100000GP) をしてしまえばよい。
      • 指輪を手に入れたらディンス王に届けてイベントクリア。
    10. No.7 闇の巫女
      • 竜の牙にいる闇の巫女を倒す。このダンジョンは地道に進むしかない。
      • 竜の牙 1F (9, 19) から 2F へ。
      • 竜の牙 2F (15, 3) から 3F へ。
      • 竜の牙 3F (4, 4) から 4F へ。マップ上では壁になっているところも反時計回りに進んでいける。
        • (18, 7) から上へ。(12, 17) から左へ。(2, 12) から下へ。
        • (7, 3) から右へ。(15, 7) から上へ。(12, 15) から左へ。(4, 12) から下へ。
      • 竜の牙 4F (15, 15) から 5F へ。
      • 竜の牙 5F (3, 10) から 6F へ。
      • 竜の牙 6F (16, 10) から 7F へ。マップと見た目が一致しないが、時計回りにマップ通りに進んでいけばよい。
      • 竜の牙 7F (4, 9) から 8F へ。
      • 竜の牙 8F からは中央部分を下っていく。(9, 14) から 7F へ。
      • 適度にピンクの扉の封印を解きながら下っていく。セーブしながら行くなら、1F の扉だけ開ければよいかも。
      • 竜の牙 1F の中央部分まで降りたら、あとは中央のワープから 9F に行って、闇の巫女（ヘリオライザ＆アイローク）を倒して結界を再生。
      • ディンス王に謁見してイベントクリア。
    11. No.44 謎の祭壇
      1. ディンス王から神々の祭壇の伝説の話を聞いてイベント開始。
      2. リンク先の情報にしたがって、6 つの祭壇に祈りを捧げる。
      • シェーベ遺跡の地下に配置されてしまったら、ロンデルギウスから時計台の鍵をもらっておく必要あり。
    12. No.51 忘れられた場所
      1. No.44 謎の祭壇をクリアしてエルミナージュに行く。雑談して「記録のワンド」をもらっておく。
        • 「魔蒼石」or「ミルストーン」で呪いを解いてから、装備→解放を繰り返してフェイムを捧げていく。
      2. 「奥の扉」を選んで忘れられた地に入り、2層/3層のボスをすべて倒す。
      3. 次の周回のためのアイテムを集めてから、雑談して 3 周目へ。

    フェイム稼ぎ（シーケンス 1）

    1. No.17 研究者の日記 / No.41 怪鳥ワーグル
      1. ノヴァ・カリスの青水晶の広場の右端にいる「王の使いハレス」と話して No.17 研究者の日記のイベント開始
      2. カレテゴの売店で、ドワーフ侍のゾアーヌに話しかけて No.41 怪鳥ワーグルのイベント開始
      3. カレテゴの売店で、エアリーバイダーの肉（鎧）を買って装備してワールドマップに出ると怪鳥ワーグルの中に入る → まっすぐ上に進んでシュートから落ちる
      4. ジェスベイラーに落ちるので、すぐ下の部屋の研究者の日記を取得
      5. ノヴァ・カリスでハレスと話す → フェイムを 3 つゲット → ハレスが仲間に加わりイベント No.18 王の使いと空遊艇が開始
    2. No.18 王の使いと空遊艇
      1. ジェスベイラーの日記のあった場所にハレスを連れていく → 逆さまになっていると言われる
      2. 右上の登り階段を登り、下層 (4, 7) のスイッチを入れる
      3. 中層 (3, 11) から左に落ちてスイッチを入れる → マリステルの声を聞く → フェイムを 3 つゲット

    フェイム稼ぎ（シーケンス 2）

    1. No.15 魅惑の花ロルファン
      1. ノヴァ・カリスの青水晶の広場の中央にいる「フリーナ」と話すとイベント発生
      2. マウレアの森に入り、上端 (x:10-12) から北西エリアへ → 右端の下から北東エリアへ → 下端の中央から南東エリアへ
      3. 南東エリア (6, 16) でロルファンを入手 → フリーナに届ける → フェイムを 3 つゲット、No.16 パルテネスヘ捧ぐが開始
    2. No.16 パルテネスヘ捧ぐ
      1. 紅茶葉とロルファンを1つずつ買ってパルテネスへ入る。ダンジョン設定で、下ボタンの動作を「振り向き」にする。
      2. パルテネス 3F のシャンデリアの下で、「南→西→東→北」の順番に振り向くと、「星空が見える」というメッセージが表示される。
      3. そのままバルコニーまで移動して、紅茶葉を捨てるとペガサスが現れて 4F に行ける。
      4. ロルファンを台座に捧げる → ノヴァ・カリスのフリーナと話す → フェイムを 3 つゲット

    フェイム稼ぎ（単独イベント）

    1. No.42 水猫のぬいぐるみ

      1. カレテゴの売店で、ドワーフ侍のゾアーヌに何度も話しかけてイベント開始
      2. ウェーン廃墟に入り、上端の右から市街地(北)のエリアへ行き、(13, 18) の部屋でウェンディーネを見逃す → 水猫のぬいぐるみを貰う
      3. カレテゴの売店でゾアーヌと話す → フェイムを 3 つゲット

    2. No.46 神木とエルフの少女

      1. マウレアの森 (北東) (4, 2) でエルフの少女と話す → 魔法の鏡を要求される
      2. 鏡の沼地 (裏) (15, 0) のドッペルゲンガーを倒す → 魔法の鏡を入手
      3. エルフの少女に届ける → フェイムを 3 つゲット

    3. No.35 かしこくなりたいニャン

      1. ニャンニャンどぐぁで話してイベント開始
      2. 知恵のアンクを 10 個買って渡す → フェイムを 3 つゲット + 0GP アイテム売買解禁。

    フェイム稼ぎ（シーケンス 3）

    1. No.45 オーガのぶどう
      1. マウレアの森 北西 (12, 11) で腹を空かせたオーガと話す → ぶどうが欲しいと言われる
      2. コートラスト要塞 1F 東側 (16, 10) でオーガの手入れ人と話す → ダイアレスに会えと言われる
      3. コートラスト要塞 3F (17, 17) で争いを聞く（これいらない？）
      4. コートラスト要塞 3F (9, 16) でダイアレスと話して倒す
      5. コートラスト要塞 1F 東側 (16, 10) でオーガの手入れ人と再び話す → ぶどうをもらえる
      6. マウレアの森 北西 (12, 11) で腹を空かせたオーガと再び話す → フェイムを 3 つゲット
    2. No.48 コートラスト後継者争い
      1. コートラスト要塞 3F (9, 16) でバルモアとヨグマの争いを止める → フェイムを 3 つゲット
    3. No.50 ぶどうに手が届かない
